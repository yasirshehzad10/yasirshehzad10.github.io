The method

Aspen, driven by code.

Aspen is where the thermodynamics lives. Some equipment has no block in it, and large studies are slow to run by hand. So I link it to MATLAB and Python through COM and let the code handle the rest.

Models Aspen doesn't have. There is no rotating packed bed block in Aspen Plus, so I wrote one in MATLAB and ran it inside the full capture loop.

Studies too big to click through. Sensitivity sweeps, cost models and optimisation run from code, and Aspen answers every case rigorously.
